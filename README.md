# سوق القرنة | Qurnah Market

المرحلة الأولى من مول إلكتروني عربي متعدد المتاجر، مبني بـReact وTypeScript وVite. تصميم أبيض وكحلي وفيروزي، RTL ومتجاوب مع الهواتف.

## التشغيل

يتطلب Node.js 22.12+ أو 24+ وnpm. لا تحتاج هذه المرحلة مفاتيح API أو حساباً مدفوعاً.

```bash
npm ci
npm run dev
npm test
npm run build
npm run preview
```

البناء يتحقق من TypeScript ثم ينتج ملفات `dist/`. الاختبارات الـ13 تتحقق من ارتباط المنتجات بالمتاجر والبحث والفلترة ومعرّفات المسارات وعرض الصفحات وحالات نفاد المخزون والموارد غير الموجودة.

## الصفحات والملفات

- `/`: البحث، إعلانات قابلة للتبديل يدوياً، الأقسام، المتاجر المميزة وأحدث المنتجات.
- `/browse`: البحث وفلترة الأقسام والتحميل التدريجي (4 منتجات في كل دفعة).
- `/browse?view=stores`: دليل المتاجر.
- `/stores/:id`: شعار المتجر وبياناته ومنتجاته.
- `/products/:id`: معرض الصور والسعر والمخزون ومواصفات المنتج ورابط متجره.
- `/merchant` و`/admin`: هيكل لوحات مع تنقل وملخصات وجداول محلية.
- `src/data/catalog.ts`: المصدر المحلي الوحيد للبيانات التجريبية.
- `src/types.ts`: أنواع المتاجر والمنتجات والأقسام.
- `src/lib/`: البحث والتنسيق واختبارات الكتالوج.
- `src/components/`: التنقل والبطاقات والتنبيهات الخاصة بـPWA.
- `src/pages/`: صفحات تُحمّل عبر `React.lazy`، وملفات JavaScript منفصلة.
- `public/images/`: رسوم أصلية توضيحية WebP محفوظة محلياً؛ توليدها اختيارياً بـ`scripts/assets.py` (يتطلب Python وPillow).
- `.github/workflows/ci.yml`: اختبارات وبناء على GitHub Actions.

المتاجر وأسماؤها وشعاراتها الحرفية والمنتجات والأسعار والصور والمخزون أمثلة توضيحية، وليست عروضاً حقيقية. لا توجد سلة أو عملية شراء أو إرسال طلب في هذه المرحلة. لا تحفظ اللوحات تغييرات، ولا توفر مصادقة أو عزل بيانات أو صلاحيات أمنية. صفحتا الإدارة والتاجر عامتان للعرض فقط، فلا تضع بيانات حقيقية أو سرية فيهما.

## Cloudflare Pages

1. اربط هذا المستودع بمشروع Pages واختر الفرع المطلوب. نشر الإنتاج يتم بعد مراجعة ودمج Pull Request.
2. Framework preset: **Vite**.
3. Build command: `npm run build`.
4. Build output directory: `dist`.
5. اضبط `NODE_VERSION=22` أو `24`. لا تحتاج متغيرات Supabase الآن.

`public/_redirects` يوفر fallback لمسارات SPA عند فتح رابط منتج أو متجر مباشرة. `public/_headers` يحدد التخزين المؤقت للأصول وترويسات أساسية. لا يوجد Worker أو خادم مطلوب. اختيار الخطة المجانية متاح وفق حدود مزود الاستضافة، دون أي خدمة مدفوعة إلزامية في الكود.

## PWA والأداء

Manifest عربي وأيقونات PNG بأحجام 192/512، Service Worker يولده `vite-plugin-pwa` أثناء البناء، وتخزين ملفات التطبيق والصور المحلية للتصفح دون اتصال بعد أول زيارة. يظهر تنبيه عند توفر تحديث بدلاً من إعادة تحميل الصفحة أثناء الاستخدام. يعمل التثبيت وService Worker على HTTPS أو localhost؛ لا يفعّل خادم التطوير Service Worker.

على iPhone: افتح الموقع المنشور في Safari، ثم مشاركة ← إضافة إلى الشاشة الرئيسية. خطوط Google Fonts اختيارية للعرض؛ عند انقطاع الاتصال تُستخدم Tahoma/Arial. لا تعتمد المنتجات على خوادم صور خارجية.

الصور WebP بأبعاد محددة و`loading="lazy"` للبطاقات، وصورة الإعلان الأولى بأولوية عالية. السلايدر يدوي لتجنب الإزعاج والحركة التلقائية. يوجد دعم لتقليل الحركة، وعناوين وأزرار ذات أسماء عربية واضحة وتنقل بلوحة المفاتيح.

## المرحلة التالية

طبق مخطط SQL وSupabase Auth وسياسات RLS واختبارات عزل التجار قبل أي بيانات حقيقية. أضف رفع الصور والتعديل والطلبات والسلة وتقسيم طلبات المتاجر وأسعار الطلب المحفوظة وفق `PROJECT_PLAN.md`. مفتاح service-role لا يُرسل مطلقاً إلى الواجهة. إعدادات PWA الحالية مخصصة للكتالوج التجريبي؛ أعد تقييم التخزين المؤقت قبل إضافة بيانات خاصة أو API.
